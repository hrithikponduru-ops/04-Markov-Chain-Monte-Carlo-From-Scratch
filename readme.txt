## Setup

1. Clone the repository
2. Create virtual environment:
```bash
   python -m venv venv
```
3. Activate it:
   - **Windows**: `venv\Scripts\activate`
   - **macOS/Linux**: `source venv/bin/activate`
4. Install dependencies:
```bash
   pip install -r requirements.txt
```
5. Run training:
```bash
   python run.py
```
